## About the Project

TrustFirst Carpool is our hackathon project based on **Problem Statement 6: Carpooling that people will actually use**.

Many students and office-goers travel to nearby places at around the same time, but they may not know who else is going that way. Our idea is to make it easier to find a suitable shared ride, understand the cost, and feel more comfortable before travelling with someone.

We built a website prototype to present this idea. Some features may be shown as a demo, so the project should not be treated as a fully operational ride-booking service.

## What We Want to Solve

Finding a ride with a similar route and timing can be difficult. People can also have questions about how the travel cost will be divided and whether they can trust the person they are sharing a ride with.

Our project focuses on three simple things:

- **Finding a suitable ride:** Help users compare routes and travel times.
- **Sharing costs clearly:** Show an estimated contribution for a shared trip.
- **Building trust:** Give users useful ride and profile information so they can make a more informed choice.

## Main Features

The website is a prototype for exploring our idea. Depending on what is connected in the current demo, it may include:

- Viewing or exploring available rides
- Offering a ride or showing how a passenger could join one
- Estimating how a trip's cost could be shared
- Showing ride details and safety-related information
- A layout designed for desktop and mobile screens

Features such as identity verification, live tracking, emergency response, online payments, and real-time notifications should only be considered active if they are actually connected and tested. A sample screen or demo button does not mean that a real service is running.

## How the Cost Could Be Shared

One possible approach is to divide the agreed trip cost according to how far each passenger travels.

**Estimated share = Total shared cost × Passenger's distance ÷ Total distance travelled by all passengers**

This is a simple example for explaining the idea. The final amount would need to be rounded carefully and agreed on by the people taking the ride.

## Current Limitations

- This is a hackathon prototype, not a complete public ride-booking service.
- Any sample rides, users, or ratings should be treated as demo information.
- Real route matching, identity checks, live location sharing, payments, and emergency support need additional development and testing if they are not already connected.
- Users should not rely on demo safety information as a substitute for real verification.

## Future Improvements

If we continue developing TrustFirst Carpool, we would like to:

- Improve matching based on route overlap and departure time
- Make recurring college and office commutes easier to arrange
- Add secure sign-in and reliable profile verification
- Support trip sharing and useful ride-status updates
- Test the website with students and regular commuters
